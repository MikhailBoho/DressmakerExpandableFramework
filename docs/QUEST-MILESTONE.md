# Playable sample milestone — 0.2.0

The user confirmed 0.1.4 presentation works and authorized sample quests. This release implements a small authored chain plus an independent client, ready for the first gameplay play-test.

| Step | Implementation | Validation remaining |
| --- | --- | --- |
| Stable native definitions | Two clients, three quests, loader registry in Awake | Confirm restoration on a real saved game |
| Explicit acceptance | Agreement page, native measurement confirmation | Accept alongside existing work |
| Multiple requests | Native active commission list and switch method | Check each dress/design survives switching and reload |
| Scoring and retries | Native quality/colour scoring; failed checks retain work | Submit unmet requirements, adjust, resubmit |
| Delivery and payment | Native CompleteQuest/Archive/Save; once-only guard | Confirm payment/progression once and completed state after restart |
| Recurring character | Juniper's second request gated by successful first completion | Follow-up appears unread and can be completed independently |

Juniper's first event is the telescope unveiling; her return letter invites a dress for public stargazing. Beatrice's conservatory celebration is available independently from the beginning. The chain is deliberately finite and not repeatable in this test release.

The next content work should follow this gameplay test: tune thresholds, payments and measurement flow, then convert the remaining four writing samples into validated requests. After stable save/selection/delivery behavior, add a larger authored catalog, per-save favorites, and rotation. Runtime generation remains unnecessary for this approach.
